# Winsora DMC

Premium destination management company website — built for tour operators, travel agencies, wholesalers and corporate/MICE planners.

Not a consumer travel booking site. Positioning, copy and CTAs reflect B2B ground operations, trade products and partner enquiries.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Framer Motion
- Lucide icons
